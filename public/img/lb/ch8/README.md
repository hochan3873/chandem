# 8장 「결혼식 뒤풀이」 그림 목록 (축의금 도둑)

그림만 있습니다. 코드(data.js · sim.js · render.js)는 아직 연결 안 함 — 아래 표대로 붙이면 됩니다.
모든 그림은 Gemini(3.1 Pro)로 만들고, 기존 7장 그림과 같은 크기·여백·발 위치로 맞췄습니다.
경로는 전부 `public/img/lb/` 기준입니다.

## 공통 규칙 (기존 그림과 같음)

| 종류 | 크기 | 칸 | 비고 |
|---|---|---|---|
| 기본 그림 `e_<id>.webp` / `h_<id>.webp` | 256×256 | 1 | 투명. 진상: 위 12 · 발 238 / 멤버: 위 22 · 발 238 |
| 걷기 `e_<id>_walk.webp` | 3072×256 | 12칸 (256씩) | render.js `frames: 12, fps: 10` 그대로. 발 y≈238 |
| 쓰러짐 `e_<id>_die.webp` | 2048×256 | 8칸 | `frames: 8, fps: 14` |
| 공격 `e_<id>_attack.webp` / `h_<id>_attack.webp` | 2048×256 | 8칸 | `release: 3` (4번째 칸에서 투사체/타격) |
| 도감 `dex/<id>.webp` | 640×640 | 1 | 진상: 위 20 · 발 630 / 멤버: 위 20 · 발 620 |
| 도감 고화질 `dexhq/<id>.webp` | 800×1200 | 1 | 멤버 전용. 썸네일 `dexhq/thumb/<id>.webp` 400×600 |
| 스테이지 디오라마 `dio/sNN.webp` | 640×640 | 1 | 투명, 아이소메트릭 떠 있는 땅 |

## 1. 챕터 배경

## 2. 진상 5종 (일반)

| id (제안) | 이름 | 파일 | 특징 / 연결 메모 |

| `buffet` | 뷔페 싹쓸이 아줌마 | `e_buffet.webp`, `_walk`(12), `_die`(8), `dex/buffet.webp` | 보라 한복 드레스, 산더미 접시 + 포장 봉지. 쓰러질 때 음식이 쏟아지고 케이크 뒤집어씀 |

| `showoff` | 하객룩 과시녀 | `e_showoff.webp`, `_walk`(12), `_die`(8), `dex/showoff.webp` | 금색 스팽글 원피스, 셀카. 쓰러짐 = 폰 배터리 방전 → 주저앉아 삐짐(비구름) |
| `drunkfriend` | 술 취한 신랑 친구 | `e_drunkfriend.webp`, `_walk`(12), `_die`(8), `dex/drunkfriend.webp` | 턱시도·셔츠 빼입음, 초록 병. 쓰러짐 = 미끄러져 바닥에서 쿨쿨(Zzz) |

공격 그림(`_attack`)은 일반 진상 5종에는 없음 — 기존처럼 `ENEMY_ATK`(예: `shove`, `bottle`, `slap`)로 처리하면 됨.
제안: envthief `shove`, buffet `bag`, badsinger `slap`, showoff `slap`, drunkfriend `bottle`.

| 파일 | 크기 | 메모 |
|---|---|---|
| `h_subin.webp` | 256×256 | 게임 안 그림 (작은 머리 큰 꼬마 그림체, 라벤더 들러리 드레스, 장미 부케 + 분홍 리본, 윙크) |

## 6. 확인한 것

- 모든 투명 그림은 어두운 바탕 위 접촉 시트로 확인 — 네모난 배경 찌꺼기 없음 (디오라마 전구 주변의 작은 빛 번짐은 일부러 남김).
- 12칸/8칸 띠는 칸마다 발 y≈238, 칸 경계 밖으로 넘치지 않게 축소.
- 알려진 작은 흠: `e_mid_hallmgr_die` 6번째 칸 위쪽에 종이 한 장이 떠 있음, `e_boss_bestman_attack` 5~6칸은 두루마리 끝이 칸 경계에서 잘림, `dio/s72` 축의금함 글자가 '福'.
