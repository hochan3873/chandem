# ♠ 찬덤 (Chan'dem Hold'em)

친구들끼리 각자 휴대폰으로 접속해서 즐기는 **한국어 모바일 웹 노리밋 텍사스 홀덤**.
게임 칩은 현금 가치가 없는 친목용 점수이며, 입금·출금·환전 기능은 없습니다.

## 0. 인터넷 주소 (PC 없이 접속)

**https://chandem.onrender.com** — Render 무료 요금제(싱가포르)에 올라가 있음.
- 15분 동안 아무도 안 쓰면 잠들고, 다음 첫 접속은 50초쯤 걸림. 게임 전에 한 번 먼저 열어 두기.
- 서버가 잠들거나 재시작되면 진행 중이던 방은 사라짐(새로 만들면 됨).
- 코드를 고친 뒤 반영: GitHub(hochan3873/chandem)에 푸시 → Render 대시보드 chandem → Manual Deploy → Deploy latest commit.
  (저장소를 '공개 저장소 주소'로 연결해서 자동 배포는 꺼져 있음)

## 1. 실행 방법 (내 PC에서)

필요한 것: [Node.js](https://nodejs.org) 18 이상 (이 PC에는 v24 설치됨)

```bash
cd "D:\바탕화면\브이에스코드 폴더\찬덤"
npm install        # 처음 한 번만
npm start          # 서버 켜기
```

서버가 켜지면 이렇게 나옵니다.

```
  ♠ 찬덤 서버가 켜졌어요
  이 컴퓨터에서:   http://localhost:3000
  같은 와이파이 휴대폰에서: http://192.168.x.x:3000
```

- **같은 와이파이**에 연결된 휴대폰에서 `http://192.168.x.x:3000` 을 열면 됩니다.
- PC에서 방을 만들어도 초대 링크·QR코드는 자동으로 `192.168.x.x` 주소로 만들어져서 친구 휴대폰에서 바로 열립니다.
- 처음 켤 때 윈도우 방화벽 창이 뜨면 **개인 네트워크 허용**을 눌러 주세요. (안 누르면 휴대폰에서 접속이 안 됩니다)
- 밖에 있는 친구(다른 인터넷)까지 부르려면 외부 주소가 필요합니다. 예) `npx cloudflared tunnel --url http://localhost:3000` 으로 받은 https 주소를 `PUBLIC_URL` 로 지정해서 켜기:
  `set PUBLIC_URL=https://xxxx.trycloudflare.com && npm start` (PowerShell: `$env:PUBLIC_URL="https://..."; npm start`)
- 포트를 바꾸려면 `PORT=4000` 환경변수.

## 2. 직접 확인하는 순서

| 확인할 것 | 방법 |
|---|---|
| 방 만들기 | 첫 화면 → **방 만들기** → 시작 칩·블라인드·인원·턴 시간·리바인·비밀번호·승인 설정 → 만들기 |
| 초대 QR | 대기실 맨 위 QR코드를 친구 휴대폰 카메라로 스캔 → 참가 화면으로 이동 |
| 방 입장 | 닉네임 입력 + 캐릭터 선택(자동이면 겹치지 않게 배정) → 참가 (같은 닉네임이면 `민수 (2)` 처럼 자동 구분) |
| 한 판 진행 | 친구들이 **준비 완료** → 방장이 **게임 시작** → 폴드/체크/콜/레이즈/올인 |
| 리바인 | 칩이 시작 칩의 절반보다 적어지면 위쪽에 **리바인** 버튼 → 다음 판부터 적용 |
| 새로고침 복구 | 게임 중 휴대폰에서 새로고침 → 같은 자리, 같은 카드로 돌아옴 |
| 혼자 연습 | 첫 화면 **🤖 혼자 연습하기** → 봇 1~5명과 바로 시작. 대기실에서 방장이 **🤖 봇 추가**로 빈자리를 채울 수도 있음 (봇은 `server/bot.js`, 칩이 떨어지면 자동 충전, 사람이 없으면 멈춤) |
| 봇 스크립트 | `npm run bots` → 소켓 봇 3명이 있는 방. 기존 방에 봇 추가: `node scripts/bots.js 방코드 2` |

## 3. 자동 테스트

```bash
npm test                 # 규칙 엔진 + 서버(실시간 통신) 테스트 23개
node scripts/e2e.js      # 실제 브라우저(에지/크롬) 3대로 한 판 끝까지 플레이 + 스크린샷
```

테스트하는 핵심 규칙: 족보 10종, 휠 스트레이트(A-2-3-4-5), 7장 중 최선의 5장, 키커·완전 동률 분배,
메인/사이드 팟(3명 이상 서로 다른 올인 + 폴드한 사람 칩), 나누어떨어지지 않는 칩, 헤드업 블라인드·행동 순서,
최소 레이즈, 불완전한 올인 레이즈(레이즈 재개방 안 됨), 칩이 부족한 콜, 짧은 빅 블라인드, 전원 폴드 즉시 승리,
무작위 300판 칩 총량 보존, 차례가 아닌 행동 거절, 남의 홀카드 비공개, 새로고침 복구, 비밀번호·승인, 방장 이전,
리바인 횟수·적용 시점, 서버 재시작 후 방 복구.

## 4. 규칙·운영 기준

- **딜러 버튼**: 매 판 시계방향으로 다음 참가자에게. 2명일 때는 딜러가 스몰 블라인드이고 프리플랍에 먼저 행동.
- **시간 초과**: 체크할 수 있으면 자동 체크, 아니면 자동 폴드. 2번 연속 시간 초과면 **자리 비움**(다음 판부터 제외, 버튼 한 번으로 복귀).
- **연결 끊김**: 판은 그대로 진행(차례가 오면 시간 초과 규칙 적용). 60초 넘게 끊긴 사람은 다음 판에서 빠짐.
- **방장 권한 이전**: 방장이 나가면 즉시, 방장 연결이 30초 넘게 끊기면 자동으로 → 연결된 참가자 중 **가장 먼저 들어온 사람**(참가자 우선, 없으면 관전자). 방장이 직접 넘길 수도 있음.
- **리바인**: 방장이 켠 경우만. 칩(진행 중인 판에 건 칩 포함)이 시작 칩의 절반 미만일 때 신청, 횟수 제한, **다음 판 시작 때 적용**(진행 중인 판의 칩·팟에는 영향 없음).
- **폴드 버튼**: 체크할 수 있을 때는 실수 방지를 위해 막힘.
- **중간 참가**: 게임 중에 들어오면 빈자리에 앉고 다음 판부터 카드를 받음.
- **보안**: 셔플(암호학적 난수)·덱·베팅·정산은 전부 서버. 각 휴대폰에는 자기 카드만 전송, 쇼다운 때 남은 사람 카드만 공개.
- **저장**: 방 상태는 `data/rooms.json` 에 저장되어 서버를 껐다 켜도 복구됨. 12시간 활동 없는 방은 정리.

server/index.js          Express + Socket.IO 서버, QR, 저장/복구
public/                  휴대폰 화면 (index.html, js/, css/, img/, sounds/)
test/                    자동 테스트
scripts/bots.js          테스트용 봇, scripts/e2e.js 브라우저 검증
