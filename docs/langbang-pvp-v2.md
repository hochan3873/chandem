# 랑방대전 1:1 대전 v2 — "맞대결" 설계

지금 대전은 각자 자기 판을 막으면서 진상을 "보내기"만 해서, 상대가 옆방에 있는 느낌이다.
v2 는 **한 화면에서 서로 마주 보고 싸운다.** 상대 멤버가 보이고, 내 스킬이 상대 멤버를 묶고, 상대도 나를 묶는다.

## 1. 화면 (폰 세로 360×640 기준)

```
┌──────────────────────────┐
│ 상대 이름 · 등급 · 입구 ███░ │  ← 위 띠 (상대 입구 · 남은 시간)
│ ═══ 상대 입구 ═══          │
│  [멤버][멤버][멤버][멤버]   │  ← 상대 멤버 4명 (상태 아이콘 · 스킬 준비 빛)
│     ↑ 상대 쪽 진상 ↑        │
├──── 가운데 줄 (단계 · 시간) ─┤  ← 보낸 진상 · 견제 기술이 이 줄을 넘어간다
│     ↓ 내 쪽 진상 ↓          │
│  [멤버][멤버][멤버][멤버]   │  ← 내 멤버 4명
│ ═══ 내 입구 ═══            │
│ [스킬][스킬][스킬][스킬]    │  ← 누르면 스킬 (자동 조준)
│ [벤치][벤치] [정신차려][보내기][총공지] │
└──────────────────────────┘
```

- 위쪽 절반 = 상대 판을 **180도 돌려서** (상대 입구가 맨 위). 아래쪽 절반 = 내 판.
- 진상은 가운데 줄에서 나와 각자 입구로 걸어간다. 내가 보낸 진상은 가운데 줄을 넘어 상대 쪽으로 간다.
- 상대 멤버를 누르면 **견제 표적**(조준 표시). 안 누르면 상대에서 제일 잘 싸우는 멤버를 자동으로 노린다.
- 내 판의 진상을 누르면 **집중 공격**(지금 있는 기능 그대로).
- 스킬 버튼: 누르면 자동 조준 · **끌어서 내 판에 놓으면 그 자리** (끄는 동안 범위 표시 · 판 밖에서 놓으면 취소).

## 2. 이기는 법

- **입구 레이스**: 상대 입구가 먼저 무너지면 승리.
- 한 판 **4분**. 단계는 지금 대전을 4분에 맞춰 당긴다: 72초 과열(보내기 ×2) → 120초 폭주(보스 묶음 · 자동 중간 보스) → 168초 서든데스(큰 웨이브 · 입구 무너짐) → 4분 판정.
- 4분 판정: 입구 남은 % → 처치 수 → 무승부 (지금 규칙 그대로).

## 3. 상대에게 넘어가는 것

| 무엇 | 어떻게 |
|---|---|
| 보낸 진상 | 처치 10명 = 진상 5명 · 30명 = 중간 보스 (지금과 같음, 1초 뒤 도착) |
| **견제 기술** | 내 멤버가 스킬을 쓰면, 역할에 맞는 상태이상이 상대 멤버 한 명에게 날아간다 (0.7초 비행 — 화면에서 보인다) |

역할별 견제 (스킬 한 번 = 견제 한 번):

| 역할 | 효과 |
|---|---|
| 군중 제어 | 상대 멤버 **기절** 1.5초 |
| 단일 저격 | 상대 멤버 **홀림** 2초 (공격 못 함) |
| 약화·특수 | 상대 멤버 **침묵** 3초 (스킬 못 씀 · 쿨 멈춤) |
| 범위 공격 | 상대 멤버 **둔화** 3초 (공격 속도 −35%) |
| **탱커** | 견제 대신 **우리 팀 방패**: 8초 안에 오는 견제 1번을 막는다 |
| **지원·회복** | 견제 대신 **우리 팀 해제**: 상태이상 전부 풀고 2초 면역 |

막는 법 (카운터):
- **정신 차려!** 버튼: 제일 심하게 묶인 내 멤버 하나를 바로 풀어 준다 (10초 쿨).
- 날아오는 동안 그 멤버를 **벤치와 바꾸면 빗나간다**.
- 멤버 저항 그대로 적용 (이소영 곁 홀림 면역, 김도훈 기절 절반 같은 기존 서포터 효과 · 멤버별 저항).
- 한 번 견제를 맞은 멤버는 끝나고 4초 동안 또 안 걸린다 (계속 묶이지 않게).
- 총공지를 쓰면 우리 팀 상태이상이 전부 풀린다.

## 4. 벤치와 교체

- 덱 6명 = **필드 4명 + 벤치 2명**. 대전에서는 산 덱 칸과 상관없이 누구나 6칸: 덱이 모자라면 가진 멤버 중 센 순서로 벤치를 채운다 (가진 멤버가 4명뿐이면 벤치 없음).
- 벤치 카드 → 필드 멤버 순서로 누르면 교체. 팀 전체 **8초 쿨**.
- 들어온 멤버는 **2초 무적**(상태이상 안 걸림) · 나간 멤버의 레벨을 그대로 이어받는다.
- 레벨업 카드 · 증강은 대전에서 **자동**으로 고른다 (손은 스킬 · 견제 · 교체에 집중).

## 5. 눈덩이 막기

- 입구가 상대보다 20%p 이상 적으면 **추격**: 총공지 충전 +30% · 보내기 비용 −20% · 나에게 오는 견제 시간 −25%.
- 화면 진상 최대 수 · 보낸 진상이 넘치면 수 대신 체력으로 (지금 규칙).
- 견제 뒤 4초 면역 (위).

## 6. 매칭 · AI · 끊김

- **매칭**: 새 전투력 잣대(대전 한도: 강화 +10 · ★3 · 영웅 장비)로 ±15% 안 상대부터, 5초마다 10%p 씩 넓힌다. 점수 차도 같이 본다.
- 20초 동안 사람이 없으면 **같은 전투력 AI**. 대기 중 **[AI와 바로 대전]** 버튼, **방 코드 · 초대 링크**도 그대로.
- AI 는 사람처럼 0.4~1.2초 늦게 스킬 · 정신 차려 · 교체 · 보내기를 쓴다.
- **끊김**: 15초 동안은 AI 가 대신 조종(자동). 다시 들어오면 그대로 이어서. 15초가 지나면 기권패.
- 배속은 **×1 만**.

## 7. 점수 · 보상

지금 대전과 같다: 로그인한 사람끼리 점수(레이팅) 변동 · AI 판은 60% · 하루 보상 · 첫 승 2배 · 등급 달성 우편 (live.js 그대로).

## 8. 네트워크 방식 — 서버가 판을 돌린다 (server-authoritative)

**고른 것: 서버가 두 사람 판을 모두 돌리고, 화면에는 짧게 줄인 장면(스냅샷)을 1초에 10번 보낸다. 화면은 0.1초 늦게 부드럽게 이어 그린다.**

왜 lockstep(두 폰이 똑같이 계산)이 아니냐:
1. `sim.js` 에 `Math.sin/cos/pow/atan2` 같은 계산이 85곳. 아이폰(Safari)과 안드로이드(Chrome)는 이 값이 마지막 자리에서 다를 수 있어, 4분이면 두 화면이 어긋난다.
2. 어긋났을 때 서버 장면으로 되돌리려면 판 전체(멤버 · 진상 · 투사체 · 수많은 타이머)를 통째로 옮겨야 하는데 너무 크고 복잡하다.
3. 서버는 이미 AI 상대용으로 `sim.js` 를 돌리고 있다 — 재 보니 한 판(두 판 합) 1초에 약 6ms, 가볍다.
4. 서버가 판을 돌리니 **속임수가 안 통하고 결과도 서버가 정한다** (처치 수 · 입구를 화면이 보고하지 않는다).

입력 지연: 스킬을 누르면 서버까지 갔다 오는 시간(보통 0.1~0.2초) 뒤에 효과. 버튼은 바로 눌린 표시가 나서 답답하지 않게.

전송량 (Render 무료 전송량 고려): 장면을 통째로 바이너리 한 통으로 묶는다 (멤버 9바이트 · 진상 7바이트 · 진상 종류 이름은 처음 한 번만). 1초 5번 · 상대 판 진상은 3번에 2번 → 실측 한 사람당 1초 약 1.4~1.7KB, 한 판(3~4분) 약 230~320KB (예전 방식의 약 1/6).

서버 확인: 1초 입력 8번(순간 12번)까지 · 슬롯 · 벤치 번호 · 쿨 · 게이지 · 상태(기절 · 침묵이면 스킬 X) 확인 · 이상한 값은 버린다.

결정성 테스트: 같은 시드 + 같은 입력이면 서버 판의 상태 해시가 똑같다 (다시보기 · 버그 재현용).
